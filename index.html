Falta conectar el tablero con el Excel

Este tablero lee directamente el archivo en OneDrive y se actualiza solo, en segundos, cada vez que alguien guarda un cambio. No hay que cargar ningún archivo.

Para activarlo, TI debe completar una sola vez tres datos al inicio de este archivo:

  1. CLIENT_ID: Id de la aplicación registrada en Microsoft Entra ID.
  2. TENANT_ID: Id de directorio de Finahogar.
  3. FILE_SHARE_URL: vínculo del Excel en OneDrive o SharePoint.

Cómo conectar el tablero con el Excel

El tablero solo lee el Excel; no puede modificarlo. Cada persona entra con su cuenta de Microsoft de la empresa y ve los datos solo si tiene acceso al archivo. Cuando alguien guarda un cambio, el tablero se actualiza solo en unos segundos.

  1. Publicar este archivo con el nombre index.html en una dirección https:// (por ejemplo, GitHub Pages).
  2. En entra.microsoft.com: Entra ID → Registros de aplicaciones → Nuevo registro, cuentas solo de este directorio, plataforma Aplicación de página única (SPA) y como URI de redirección la dirección del paso 1 terminada en /.
  3. En Permisos de API: Microsoft Graph, permiso delegado Files.Read.All.
  4. Copiar el Id. de aplicación (cliente) y el Id. de directorio (inquilino) en el bloque CONFIG al inicio del script.
  5. En SharePoint u OneDrive: Compartir → Copiar vínculo del Excel y pegarlo en FILE_SHARE_URL.
  6. El Excel debe conservar la tabla TblCreditos y tener activado el Autoguardado.

Este archivo no contiene datos de clientes: todo se lee del Excel después de iniciar sesión.
